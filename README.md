## ✨ Overview del Proyecto

**Residence 01** (`REF: 2026-EX01`) es una plataforma web desarrollada para exhibir desarrollos inmobiliarios y proyectos de arquitectura de categoría *Luxury Premium*. 

Remplaza los brochures tradicionales en PDF por una experiencia digital inmersiva basada en:
* **Showroom Cinematográfico:** Reproducción fotograma a fotograma (Scrub de 556 WebP frames) controlada por el scroll del usuario.
* **Galería 3D WebGL en Tiempo Real:** Shaders tridimensionales con deformación física de lente en función de la velocidad de arrastre.
* **Anatomía del Proyecto Interactivas:** Visor de planos en tiempo real (Vistas, Cortes, Plantas).
* **Dossier Técnico Ejecutivo:** Pliego completo de especificaciones constructivas, estructurales y MEP.

🌐 **Demo en vivo:** [https://architect-showcase-two.vercel.app/](https://architect-showcase-two.vercel.app/)

## 🏗️ Especificaciones Constructivas & Memoria Técnica

### Capítulo 01 — Estructura y Albañilería
* **Fundaciones:** Platea de fundación en hormigón armado de $25\text{ cm}$ de espesor con vigas perimetrales de rigidez ($40\times 60\text{ cm}$). Hormigón tipo **H-25**. Doble malla electrosoldada Q188 y armadura de refuerzo acero ADN 420. Sub-base de tosca compactada de $40\text{ cm}$ con film de polietileno de 200 micrones.
* **Estructura de Elevación:** Sistema aporticado independiente. Hormigón estructural **H-30** ($300\text{ kg cemento/m³}$). Losas macizas de $15\text{ cm}$ y $18\text{ cm}$ ejecutadas *in situ* con encofrado fenólico plastificado de $18\text{ mm}$ para terminación *Hormigón Visto*.
* **Cerramientos Opacos:** Muros exteriores de Bloques HCCA (Retak) de $20\times 19\times 50\text{ cm}$ con transmitancia térmica $K=0.60\text{ W/m²K}$.

### Capítulo 02 — Materialidades y Acabados
* **Carpinterías & Acristalamiento:** Líneas **Aluar A40 y Altezza** con Ruptura de Puente Térmico (RPT) y anodizado Negro Mate. Vidrios **DVH 5+5 Laminado / Cámara 12mm Argón / Templado 6mm Low-E**.
* **Revestimientos & Solados:** Microcemento bi-componente color *Piedra París* en PB; piso prefinish de Roble de Eslavonia ($14\text{ mm}$) en PA. Porcelanato rectificado $120\times 120\text{ cm}$ importado en baños y cocina.

### Capítulo 03 — MEP & Eficiencia Energética
* **Climatización:** Calefacción por piso radiante PEX-A con caldera de condensación Baxi. Refrigeración VRV/VRF Daikin/Mitsubishi oculta en cielorrasos con rejillas lineales.
* **Instalación Sanitaria:** Agua en termofusión PPR; tanque cisterna enterrado de $2500\text{ L}$. Termotanque solar de 300L de tubos de vacío en cubierta plana con respaldo eléctrico.
* **SmartHome / Domótica:** Tablero trifásico T1-R3. Control centralizado bajo protocolo **KNX** para iluminación DALI dimerizable, cortinas motorizadas Somfy y zonificación de clima.

## 🚀 Key Features Tecnológicas

1. **🎬 Cinematic Scroll Scrubbing:** Renderizado en Canvas 2D intercalando 556 frames WebP precargados de forma progresiva mediante GSAP ScrollTrigger.
2. **🌀 Custom WebGL Shaders (React Three Fiber):** Galería 3D en espacio tridimensional con un *Custom Shader Material* que aplica curvatura y distorsión de lente según la velocidad inercial del scroll/drag.
3. **📐 Visor Técnico de Planos:** Lógica interactiva con Framer Motion para intercalar entre vistas, cortes y plantas arquitectónicas de forma instantánea.
4. **📄 Dossier / Pliego de Especificaciones:** Módulo técnico completo para descarga e inspección de ingeniería y terminaciones.
5. **📱 Mobile First & Smooth Scroll:** Control inercial optimizado con Lenis Scroll y compatibilidad táctil nativa.

## ⚙️ Guía de Instalación y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/Tommyx66/architect-showcase.git](https://github.com/Tommyx66/architect-showcase.git)
   cd architect-showcase
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar en entorno de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Abrir en el navegador:**
   Navegar a `http://localhost:3000`
